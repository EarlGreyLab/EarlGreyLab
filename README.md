## EarlGreyLab

I work on AI that runs on hardware you own, instead of someone else's cloud.

Mostly: local language models with Ollama and Open WebUI, retrieval over
private documents, and self-hosted automation with n8n. Occasionally web
apps in React and TypeScript.

Background in electrical engineering (RWTH Aachen). Based in Lisbon.
German and English.

### Currently

Documenting a reproducible self-hosted AI setup — Ollama, Open WebUI,
SearXNG and remote access, including the parts that usually break.
